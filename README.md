# 局域网可联机（稳定版）

这是一个无需数据库的轻量联机房间示例，支持：

- 同一局域网多设备进入同一房间。
- 在线成员列表与实时消息同步（短轮询）。
- 心跳保活、掉线超时清理、断线自动重试。

## 启动方式

```bash
node server.js
```

默认监听 `0.0.0.0:8080`。

## 局域网联机步骤

1. 在一台机器启动服务：`node server.js`。
2. 找到该机器在局域网内 IP（如 `192.168.1.20`）。
3. 其他设备访问 `http://192.168.1.20:8080`。
4. 输入昵称 + 相同房间号即可联机。

## 稳定性设计

- 前端轮询失败会退避重试并显示连接状态。
- 15 秒发送心跳，防止会话被误清理。
- 服务端 90 秒无心跳自动下线并广播提示。
- 事件队列保留最近 600 条，防止内存无限增长。
